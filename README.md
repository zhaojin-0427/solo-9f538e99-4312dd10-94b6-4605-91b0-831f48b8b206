# 公交时刻表换版 · 到站接驳核查

排班员在时刻表换版前，用本应用核查同一换乘站的新旧两版时刻表里，哪些到站班次会失去接驳。

## 核查规则

1. 上传同一换乘站的**新旧两版 CSV**，填写核查日期范围（含首尾）与最长等车分钟数。
2. 按**班次号**匹配两版在**同一运营日都开行**的到站班次。
3. 等待时间从各版**自己的到站时刻**起算，发车不早于到站且等待分钟数 **≤ 上限（达到上限仍可接驳）** 即视为可接驳。
4. 分钟数从运营日零点起算、**可跨午夜**；接驳发车可属于相邻运营日（到站后午夜前后的发车都会纳入）。
5. 临时加开/停运按**班次自己的运营日**覆盖周历：停运日即使命中星期也不开行，加开日即使不命中星期或不在常规区间内也开行。
6. 对每个共同到站班次，找出**旧版有车可接、新版无车可接的首个运营日**，并列出该日旧版全部可接发车班次及其自身运营日与等待时间。
7. 任一版 CSV 存在问题行时，只标出问题行（物理行号+班次号+原因），**暂不出结论**。
8. 运营日按日历跳跃查询（常规流按星期跳、加开流按日期跳，二路归并并跳过停运日），跨多年的范围也不会逐日展开或试算。

## CSV 格式

UTF-8 编码，表头顺序不限，支持中英文表头：

| 列 | 说明 |
| --- | --- |
| 班次号 / trip_id | 同班次号在同一文件内不可重复 |
| 类型 / kind | `到站`/`发车`（或 arrival/departure） |
| 分钟数 / minute | 从本运营日零点起算的非负整数，可 ≥1440 表示跨午夜（1470 = 次日 00:30），上限 10079 |
| 常规开始日 / start | YYYY-MM-DD |
| 常规结束日 / end | YYYY-MM-DD，不得早于开始日 |
| 星期 / weekdays | 1-7（周一到周日），支持 `1,3,5`、`1-5`、中文 `一三五` |
| 临时加开日期 / added | 多个日期用分号分隔，可空 |
| 停运日期 / suspended | 多个日期用分号分隔，可空；同一日期既加开又停运视为问题行 |

示例见 `samples/old.csv`、`samples/new.csv`，首页也可直接下载。

## 启动方式

### Docker Compose（推荐）

```bash
docker compose up --build
# 浏览器打开 http://localhost:8000
```

### 本地直接运行

```bash
pip install -r requirements.txt   # 仅依赖 Flask
./run.sh                          # 或 python -m flask --app app.web run --host 0.0.0.0 --port 8000
```

## 自测

仅使用 Python 标准库（无需 pytest）：

```bash
python -m unittest discover -s tests -t .
```

## 目录结构

```
app/
  calendar.py    运营日历：常规区间+星期、加开/停运覆盖，运营日跳跃查询
  parser.py      CSV 解析与逐行校验
  analyzer.py    跨午夜接驳计算与换版失去接驳分析
  web.py         Flask 路由与表单校验
  templates/     核查页、结果页、问题行展示
samples/         可下载的示例 CSV
tests/           单元/端到端测试（unittest）
```
